# Song Research

Hiérarchie : déclaration directe de l'artiste/producteur > crédits officiels > entretiens collaborateurs > presse musicale reconnue > académique > blogs (à éviter ; jamais seuls).

1. WebSearch (standard, puis extended si maigre) : « <titre> <artiste> interview meaning », « producer », « sample », « credits », presse FR.
2. Remonter à la source originale (une reprise de dépêche ≠ confirmation indépendante). Les fermes SEO (zerowastesonoma, monitoring.toky…) sont exclues.
3. Tableaux séparés : faits documentés / déclarations de l'artiste / interprétations critiques / usage TikTok observé / incertain. Statut ☐ / ✅ par ligne.
4. ≥ 2 sources indépendantes pour chaque affirmation du script ; sinon reformuler en « une lecture possible… » ou retirer.
5. `sources.md` : URL, média, auteur, date, type, affirmations soutenues, ouverte oui/non.
6. Ne jamais écrire « l'artiste voulait dire » sans citation directe. Aucune longue citation de paroles.
