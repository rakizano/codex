# Journal — « Time » (Pink Floyd)

- Style d'animation : **Bang Motion, gaya 4 « buku sketsa vintage »** (recommandé par le skill pour histoire/biographie) : papier sépia, gravures SVG hachurées originales, Playfair/Garamond/Cinzel, annotations à la main rouille, surligneur or ; caméra kolase (gros plan → glisse → plan large → texte) et push-through entre scènes placées dans un grand monde ; coupes calées sur le beat.
- Rendu : HTML + GSAP (npm, vendored) → `pipeline/render_html.cjs` (Playwright, image par image, 30 fps) → MP4 H.264/AAC.
- Voix : Piper UPMC « Pierre » (prononciations vérifiées en IPA : Pinnque Floïde, Taillme, Rodjeur Ouôteurse, Alanne Parsonnse) — DNSMOS 3,42.
- Musique : nappe originale 66 BPM + tic-tac générique ; dans la scène de l'antiquaire, 10 horloges à vitesses différentes + sonnerie de réveil (sons procéduraux, pas d'extrait du morceau). Le vrai morceau : son officiel TikTok, ou fichier sous licence dans `music/licence.wav`.
- Faits vérifiés par extraits de recherche (voir sources.md) ; pages originales non ouvrables depuis le conteneur.
